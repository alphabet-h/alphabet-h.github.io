# GrooveSeekDesktop サポート

> **English**: [support.md](./support.md)

## 試用版について

7 日間の無料試用版があります。試用期間中はすべての機能を使えます。試用期間が終わると購入が必要です。作成した索引 (インデックス) はお使いの PC 内に保存され、購入後もそのまま使えます。

## 購入後に「試用期間が終了しました」と表示される場合

Microsoft Store 側の権利情報が古いままになっていることがあります。次の順にお試しください。

- 購入した Microsoft アカウントで Microsoft Store にサインインしているか確かめる
- Microsoft Store からサインアウトし、PC を再起動してからサインインし直す
- Windows の「設定」→「アプリ」→「インストールされているアプリ」で本アプリの「修復」、直らなければ「リセット」を行う
- それでも直らない場合は Microsoft Store から本アプリをいったんアンインストールし、再インストールする

作成した索引は購入後もそのまま使えますが、「リセット」と再インストールでは索引と設定が消え、次回起動時に作り直しになります。

## 索引に入らない文書がある場合

次の文書やフォルダは索引に入りません。検索結果にも、検索前の文書一覧にも出ません。

- 1 つの大きさが 50 MB を超える文書 (Word・Excel・PowerPoint・PDF・Markdown・テキストのいずれも)
- 名前が `.` (ピリオド) で始まるフォルダ、`node_modules` という名前のフォルダ、ごみ箱 (`$RECYCLE.BIN`)、`System Volume Information` の中
- 本アプリが読めないフォルダ (アクセス権が無い、OneDrive 等でまだ PC に取り込まれていない、切断されたネットワークドライブなど) の中
- パスワードで保護された PDF や Office の文書

対応する形式は Word (`.docx`)、Excel (`.xlsx`)、PowerPoint (`.pptx`)、PDF (`.pdf`)、Markdown (`.md`)、テキスト (`.txt`) です。古い形式 (`.doc` / `.xls` / `.ppt`) には対応していません。

## 動作環境

- Windows 10 version 2004 以降、または Windows 11 (x64)
- それより古い Windows 10 では入れられません。Windows Update で version 2004 以降に更新してからお使いください
- 初回のモデル取得にインターネット接続と、約 2.3 GB 以上の空き容量が要ります (索引の分はこれとは別に要ります)
