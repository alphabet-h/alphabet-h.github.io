# GrooveSeekDesktop プライバシーポリシー

> **English**: [privacy.md](./privacy.md)

- 発行者: こしあん
- 対象: Microsoft Store で配布する Windows アプリ「GrooveSeekDesktop」
- 制定日: 2026年9月30日

GrooveSeekDesktop (以下「本アプリ」) は、利用者が選んだフォルダの中の文書を、利用者の PC の中だけで索引にして検索するアプリです。
本ポリシーは、本アプリが扱う情報とその扱い方を説明します。

## 集める情報

本アプリは、利用者の情報を集めません。

- 索引にする文書の中身、ファイル名、フォルダの場所、入力した検索語は、PC の外に送りません。
- 発行者 (こしあん) が利用者の情報を受け取る仕組みはありません。

## 外への通信

本アプリがインターネットに接続するのは、検索に使うモデル (約 2.3 GB) を Hugging Face (`huggingface.co`) と、Hugging Face の配信用のサーバから取得する時だけです。接続には IPv4 を使います。

- 取得するのは、次の時だけです。
  - 初めて使う時
  - 取得がつながらずに止まった時 (少し待ってから自動でやり直します。最初の 1 回を含めて 5 回まで試します)
  - 取得の途中で本アプリを閉じた後、次に起動した時 (取得済みの分の続きから取得します)
  - 自動のやり直しでも取得できなかった後に、利用者が「再試行」を押した時
  - 取得済みのモデルが読めなくなっていた時 (読めない分を取得し直して直します)
- 取得の際、これらのサーバには通常の HTTPS の要求が届きます。これには利用者の IP アドレスなど、インターネットで通信する時に一般に相手へ届く情報が含まれます。
  Hugging Face がこれらの情報をどう扱うかは、Hugging Face のプライバシーポリシーによります。
- この通信で、文書の中身や検索語を送ることはありません。

## PC に置くもの

本アプリは、次のものを利用者の PC の中の、本アプリ専用の場所 (Windows がアプリごとに用意する私的な場所) にだけ置きます。

- 設定 (選んだフォルダの場所など)
- 動作の記録 (ログ)
- 文書の索引
- 取得したモデル

索引にするフォルダは利用者が選びます。これらの情報はすべて利用者の PC の中にあり、発行者は持っていません。これらは PC の外に送りません。消したい時は、本アプリをアンインストールしてください。アンインストールすると、これらはすべて消えます。

## telemetry (利用状況の送信)

本アプリには、利用状況やエラー情報を発行者に送る仕組み (telemetry) はありません。広告も表示しません。

## Microsoft Store / Windows が集める情報

本アプリの入手・更新・アンインストールや Windows の動作に伴って Microsoft Store や Windows が集める情報は、本アプリではなく Microsoft の方針によって扱われます。
詳しくは Microsoft のプライバシーに関する声明をご覧ください。

## 本ポリシーの変更

本ポリシーを変えた時は、このページを更新し、上の日付を改めます。
